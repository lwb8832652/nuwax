# NewX UI 重构

本版本位于 `newx`，参考 Design NewX-like Prototype 的视觉和导航结构，复用 nuwax 的业务页面、接口、编辑器与会话逻辑。

## 导航与功能对应

| NewX 入口 | 原功能 |
| --- | --- |
| 专家 · 技能 · 连接器 | 智能体开发、技能、MCP |
| 工作流 · 插件 | 工作流与插件管理 |
| 知识库 · 数据表 | 知识库与数据表管理 |
| 各资源页的团队可用 / 广场 | 原空间广场与系统广场，按资源类型展示 |
| 设置 → 我的电脑 / 模型管理 / API 密钥 / IM 机器人 | 原电脑管理、当前空间模型管理、API 密钥管理、IM 平台与机器人管理 |
| 设置 → 使用统计 | 原统计，以及订阅开启时的积分余额、订阅与增购 |
| 设置 → 更多 | 后端授权的其他原“更多”功能 |
| 工作台 → 最近编辑 | 原工作空间最近编辑的专家快捷入口 |
| 空间管理 | 原成员与设置页，保留成员管理和空间设置 |
| 日志 | 原空间综合日志查询，位于空间管理下方 |

菜单来自后端授权树，保留禁用、成员角色、空间开发开关以及订阅配置。仅获广场权限的用户保留按类型浏览已发布资源的入口。未映射的动态菜单继续保留。

我的资源沿用原创建、导入、编辑、发布、复制、删除与版本操作；广场沿用对应资源的收藏、使用、复制、订阅等既有行为。知识库公开接口仅提供发布列表，因此卡片展示真实发布摘要。数据表没有公开广场接口，不添加空的广场入口。

## 会话记录

左侧会话记录按原型使用紧凑的 48px 列表行、22px 方形专家图标和“专家 · 日期”元信息。原型没有持久搜索框或新建会话按钮，因此这两个控件不在侧栏展示；会话列表保留原接口、分页加载、状态同步、当前会话高亮和跳转逻辑。原生滚动条隐藏为原型的 3px 细指示条，同时保留滚轮、触控、键盘和拖拽滚动。

## 工作台输入区

工作台使用原 `ChatInputHome` 的上传、语音、模型、电脑、执行模式、发送与停止能力，并按原型重排输入区、快捷场景及资源卡片。输入区通过稳定的 `data-chat-*` 标记应用首页专用尺寸，避免 CSS Modules 类名导致覆盖失效。

`@` 资源选择先显示资源类型，再进入搜索和选择。技能仍受原 `allowAtSkill` 与智能体类型限制，使用原技能查询接口并传递 `skillIds`。其他资源来自当前智能体可手动调用的 `manualComponents`，通过原 `infos` / `selectedComponents` 传递组件 ID；手动配置的技能也使用组件 ID，不混入 `skillIds`。不把原型演示数据或广场资源 ID 当成可调用组件。

切换快捷场景时清除旧资源选择，并忽略上一个场景尚未完成的详情请求，避免将其他专家的资源带入新会话。

选中资源不会重复切换启用状态；删除、剪切或撤销资源标签会同步本次引用启用的组件，保留原先已经启用的组件。网页应用开发沿用其自己的数据源选择器，因为该场景的数据源契约与会话手动组件不同。

工作台左侧的 Ask/Agent 对应普通智能体与任务智能体，位于模型选择前；模式菜单中的“召唤专家”列出首页已授权的聊天/任务专家，并以选中的发布智能体 ID 建立会话。原先面向任务智能体的 `yolo`/`ask` 审批策略仍通过独立执行方式控件传递，不与工作模式混淆。

清除临时召唤的专家会恢复原本的 Ask/Agent 基础模式。切换专家清除旧草稿和附件，避免上一位专家的文件进入新会话。快捷开发场景的空间选择继续使用原功能：以选中的空间 ID 创建项目。

切换专家的模型请求按目标智能体隔离，迟到的旧模型结果不会覆盖新智能体。首页“发现专家”从已授权的发现广场入口生成地址，不误跳空间广场。

## 工作台资源

资源区按当前 Tab 单独渲染：选择“我的收藏”时只显示收藏资源，切换到官方推荐、个人空间或官方空间时只显示对应分类。收藏状态刷新后会保留当前仍有效的 Tab。分类本身已表达资源范围，因此移除重复的“资源”标题；原“发现专家”入口保留在 Tab 栏右侧。

## 验证

完成生产编译、会话与任务状态回归测试、新导航和设置授权测试，以及登录后的页面导航检查。全项目 TypeScript 存在既有诊断，本次通过归一化基线比较确认没有新增诊断。

浏览器检查覆盖资源类型切换、我的/团队可用/广场、设置内 IM 机器人、电脑及 API 密钥入口。未执行真实资源删除、发布、付费购买或发送会话等有业务副作用的验收操作。

本轮工作台输入区补充了资源分类、技能查询权限、发送参数、标签删除与撤销、默认启用资源保持、Ask/Agent 路由、召唤专家、旧草稿隔离及模型请求竞态回归。浏览器实测了模式菜单与专家选择，以及桌面 1280px 与移动 390px 的输入区布局，Ask 和模型按钮均为 33px 高。

生产编译校验输出到临时目录，原 `dist` 和原 `nuwax` 前端保持原状。
